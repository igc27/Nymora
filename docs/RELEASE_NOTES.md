# Nymora 1.0.0

Independent local-first media client for Windows x64. No Nymora account or cloud service is required.

Install compatible HTTP addon manifests to browse catalogs, use declared filters/search, open movie or series metadata, choose an exact episode and request stream sources. Play supported direct HTTP(S) and HLS video inside the desktop application. Select addon English/Arabic/other Unicode subtitles or local UTF-8 SRT/VTT/ASS files. Progress, Continue Watching, your library, addon configuration and subtitle preferences stay on your device.

The application starts with no installed addons and does not provide or host movies or television content. Third-party addons are independent services.

Known limitations: codecs depend on Chromium; torrent/infoHash, legacy/IPFS transports, external-service-only sources and DRM playback are not supported. ASS/SSA uses plain text without authored styling. UTF-8 subtitles are supported. UI is English. The installer is unsigned. No automatic updater.
