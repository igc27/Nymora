# Roadmap

The first release prioritizes addon installation, catalogs/search, movie and episode stream resolution, actual in-app playback, subtitles and persistent progress.

Future work, after this flow is stable:

* Wider codec support using a separately audited native media engine.
* Styled ASS/SSA subtitles, subtitle encoding detection and additional timing controls.
* Better discovery, advanced addon management and accessibility.
* Additional themes, full Arabic UI localization and profiles.
* macOS/Linux packaging, followed by Android/Android TV investigation.
* Optional casting and explicitly opt-in cloud sync.

These are plans, not shipped features.
